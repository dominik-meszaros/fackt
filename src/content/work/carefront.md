challengeTitle: Clinic software that looks like every other clinic software
challenge: |-
  Clinics buy software to stop copying the same patient details between five tools. Most healthcare SaaS sites answer with a stethoscope photo, a list of features and a demo button, and they all look alike.

  The site needed to explain one idea, a single record behind every booking, message, visit and bill, and make it feel trustworthy enough for a practice manager to book a demo.
approachTitle: One record, shown everywhere
approach: |-
  The page leads with the idea in a calm serif headline: the operating layer for every patient interaction. Below it, an isometric record sits at the center while a booking, a message and a payment connect to it, so the one record idea is clear in a glance.

  Each workflow gets a real piece of product instead of an icon: an intake form that fills the chart, one message thread per patient, a claim that codes and sends itself. Then the full patient record, the same record in the patient's pocket, and the EHR systems it syncs with.

  Pricing is per provider, not per patient, with three plans and a short FAQ before the last call to action.

  We built it twice: in Webflow, with the CMS set up for the blog and resources, and in Framer.
