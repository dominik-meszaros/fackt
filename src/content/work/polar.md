challengeTitle: The product works while nobody is looking
challenge: |-
  Polar is a browser that does the work for you. It pulls leads, sorts the inbox and writes the report while you are busy with something else.

  The catch is that none of that shows up in a screenshot. Polar does its best work in the background, so a product screenshot shows an empty browser. The ads had to sell the finished result instead.
approachTitle: A system instead of one-off ads
approach: |-
  We designed a shared 4:5 grid with three moves repeated on every ad: rebuild the product UI as clean, ad-scale components so it still reads on a phone; stage it in a real scene operators know (a video call, a desk, a lock screen at 3 AM); and write the hook in two lowercase lines, the setup in ink and the payoff in copper.

  The type is Manrope SemiBold with tight tracking. The palette stays in warm neutrals with one copper accent, so twelve ads still read as one campaign. Four message angles carry the set: sell the outcome, not the feature; it works while you don't; one prompt is the whole interface; and not a tool, a colleague.

  Every angle comes in a light set for the daytime feed and a dark set for the work at night, six ads each. For testing, variant B keeps the same headline and landscape but brings the product into frame, to see whether showing the UI beats pure mood.
